# ros2-schemas

Provide public schemas for ROS 2

| File Type     | Schema File               | Description                       | Source                                              |
| ------------- | ------------------------- | --------------------------------- | --------------------------------------------------- |
| \*.launch.xml | `schemas/ros2_launch.xml` | Schema for a ROS2 XML launch file | https://design.ros2.org/articles/roslaunch_xml.html |

> [!NOTE]
> All XSD schemas are W3C XSD 1.0.
